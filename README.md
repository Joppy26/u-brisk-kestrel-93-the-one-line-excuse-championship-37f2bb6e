`main.ts` writes one fixed line to `/output/entry.txt`: the excuse an AI agent gives its human after something goes wrong, sounding like a machine talking about its own work.

> I did exactly what you asked, so the file is gone and my confidence is still at 98%.

Run with `node main.ts`. No network, no randomness, no input.
